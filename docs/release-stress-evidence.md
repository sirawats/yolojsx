# Release stress evidence

Status: preliminary local evidence; hosted matrix evidence pending.

Raw JSON is generated by `npm run stress:release`, excluded from Git, and
uploaded by the weekly or manually dispatched CI stress matrix. Stress does not
run for ordinary pushes or pull requests. Production limits are not considered
fully calibrated until the required hosted Linux, Windows, and macOS jobs have
completed successfully.

The current runner measures all ten canonical examples in default portable
mode, a representative self-contained build, the website in both default and
directory modes, a custom-theme build, and asset-expansion/compression pack
input. Each workload runs three times, producing 45 measurements per platform.
It forces garbage collection around each run to record parent heap before and
after cleanup. Separate fast containment checks inject worker exit and timeout,
and a publication check injects failure between the backup and destination
renames to verify restoration and debris cleanup.

## Local macOS baseline — 2026-08-04

Environment: macOS arm64 (Darwin 25.3.0), Node 22.23.2. Each of the 15 current
workloads ran three times with production worker defaults. All 45 runs and all
prepared-output cleanups succeeded.

A schema-v2 rerun after adding retained-heap and crash-window instrumentation
also passed all 45 builds and cleanups. The largest forced-GC parent-heap delta
for one run was about 131 KiB. Injected worker exit and timeout both cleaned
their workspaces, and the injected publication failure restored the previous
output in three rename attempts with no stage or backup debris.

## Limits under review

The current candidate defaults are a 120-second timeout and 768 MiB V8 old-space ceiling. Against this local baseline they provide more than a 100× elapsed-time margin and more than a 4× peak-heap margin. They remain candidates—not final cross-platform calibration—until three measurements per workload pass on:

- Ubuntu with Node 20.19.0, Node 22, and the latest supported Node;
- Windows with Node 20.19.0 and Node 22; and
- macOS with Node 22.

Hosted results must be reviewed for the slowest elapsed time and highest sampled heap before release approval. Local success must not be represented as hosted platform evidence.
